# rmegb
`rmegb` is a small C99 driver for **RobustMotion RM-EGB** compact electric grippers controlled over **Modbus RTU (RS-485)**. It runs on **Windows 10/11** and **Linux** (macOS should also work) through a USB-RS485 adapter, and can be used directly from C/C++ or built as a shared library to be used from Python and other languages.
